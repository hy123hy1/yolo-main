# 通道页任务管理子菜单设计

## 1. 背景与目标

当前系统的 AI 能力主要挂在通道页面中，以“通道 + AI 配置”的方式完成模型、类别、区域、抓拍、录像等设置。随着后端已经开始引入 `/tasks` 任务模型，现有“一个通道上一整块 AI 配置”的方式会逐步暴露出几个问题：

- 一个通道下配置多个算法时，页面结构容易混乱
- 通道基础管理、预览、电子围栏、AI 配置耦合过重
- 后续要扩展多算法、多区域、多颜色画框、事件按任务筛选时，旧结构不利于演进
- 用户心智更接近“按业务目标建任务”，而不是“在通道里打很多勾”

本次设计目标是：

- 在不打乱现有通道使用路径的前提下，把任务中心平滑接入到通道页
- 将原“AI能力”入口替换为“任务管理”
- 让用户可以围绕当前通道创建多个 AI 任务，每个任务下再配置多个算法
- 为后续事件中心、录像中心、区域能力的任务化演进打下稳定的前端结构基础


## 2. 设计原则

### 2.1 平滑迁移

任务中心不单独做一级菜单，先作为“通道”下的一个子菜单落地，避免打断用户原有操作路径。

### 2.2 职责拆分

通道页中不同子菜单各自负责单一职责：

- `预览`：只负责浏览器播放和放大预览
- `通道管理`：只负责新增、编辑、删除通道
- `任务管理`：只负责 AI 任务、算法配置、运行状态
- `电子围栏`：只负责区域流和带框预览

### 2.3 面向任务而非面向通道开关

用户配置 AI 的最小业务单元应是“任务”，而不是“给通道打开一组 AI 选项”。一个任务代表一个业务目标，例如：

- 安全帽检测
- 离岗检测
- 电子围栏入侵检测
- 人员聚集检测

### 2.4 保守落地

本轮优先做任务管理第一页的最小可用版本，不同时重做事件页、录像页和区域预览联动，避免改动过大。


## 3. 信息架构

### 3.1 通道页子菜单调整

通道页子菜单由原来的：

- 预览
- 通道管理
- AI能力
- 电子围栏

调整为：

- 预览
- 通道管理
- 任务管理
- 电子围栏

其中：

- 前端隐藏原 `AI能力` 子菜单
- 后端旧 `/channels/{id}/ai-*` 接口暂时保留，不立即删除
- 所有新建 AI 业务配置统一走 `/tasks`

### 3.2 任务管理页面布局

任务管理采用两栏布局：

- 左侧：任务列表
- 右侧：任务详情与算法配置

这是因为后续需要承载：

- 一个通道下多个任务
- 一个任务下多个算法
- 每个算法单独的类别、录像、抓拍、区域、运行状态

若采用单列表或单弹窗堆叠，会很快失去可维护性和可读性。


## 4. 页面结构设计

## 4.1 左侧任务列表区

左侧宽度建议约 300-340px，包含以下内容：

### 顶部操作区

- 页面标题：`任务管理`
- 主按钮：`新建任务`
- 搜索框：按任务名称过滤

### 任务卡片列表

每条任务卡片展示：

- 任务名称
- 状态标签：`运行中 / 已停止 / 异常`
- 算法数量
- 最近事件时间

卡片交互：

- 点击卡片切换右侧详情
- 当前选中任务高亮
- 鼠标悬停显示轻量操作按钮

卡片操作建议：

- `启动`
- `停止`
- `删除`

如果左侧无任务：

- 显示空状态文案：`当前通道暂无任务`
- 显示一个醒目的 `新建任务` 按钮


## 4.2 右侧任务详情区

右侧为当前选中任务的详情区域，自上而下分为三块：

- 基础信息
- 算法列表
- 运行状态

### 基础信息区

展示字段：

- 任务名称
- 视频源
- 帧间隔
- 创建时间
- 当前状态

操作按钮：

- `保存配置`
- `保存并应用`
- `停止任务`

按钮语义定义：

- `保存配置`：只保存任务和算法配置，不启动
- `保存并应用`：保存配置后启动任务；若已在运行，则按“保存后重新应用”处理
- `停止任务`：停止当前任务分析

### 算法列表区

此区展示当前任务下已绑定的算法，采用卡片式列表。

每张算法卡片展示：

- 模型名称
- 类别数量
- 区域数量
- 是否抓拍
- 是否录像
- 是否画框

卡片操作：

- `编辑`
- `删除`

块标题右上角按钮：

- `新增算法`

### 运行状态区

此区只读，用于帮助用户判断任务是否正常工作。

任务级状态显示：

- 总状态
- 分析帧数
- 事件数
- 最近分析时间
- 最近事件时间
- 错误信息

算法级状态显示：

- 每个算法一个小状态卡
- 展示模型名、最近检测数、最近分析时间、最近事件时间


## 5. 核心交互流程

## 5.1 新建任务流程

点击 `新建任务` 后弹出任务创建窗口。

### 弹窗字段

本轮只保留最少必要字段：

- 任务名称
- 视频源
- 帧间隔

默认行为：

- `视频源` 默认带出当前通道 `source_url`
- `关联通道` 隐式使用当前通道，不额外让用户输入

弹窗按钮：

- `创建任务`
- `取消`
- 右上角 `x`

### 创建成功后的行为

创建成功后自动：

- 左侧任务列表新增该任务
- 自动选中新任务
- 右侧切换到该任务详情
- 提示用户下一步通过 `新增算法` 继续配置


## 5.2 新增算法流程

在右侧任务详情中点击 `新增算法`，弹出算法编辑窗口。

### 弹窗字段

- 模型
- 类别
- 置信度
- 告警间隔
- 保存抓拍图
- 保存告警视频
- 录像前秒数
- 录像后秒数
- 是否画框
- 是否启用区域

若启用区域：

- 保留后续联动空间
- 本轮仅记录算法上的 `regions` 数据
- 不强制在本轮实现区域可视化编辑联动

### 保存成功后的行为

- 更新右侧算法列表
- 更新任务详情中的算法数量
- 不自动启动任务，避免用户在未检查前误运行


## 5.3 启动与停止流程

### 保存并应用

用户点击 `保存并应用` 时：

1. 保存任务基础信息
2. 保存当前任务下算法配置
3. 调用任务启动接口
4. 刷新任务状态区

### 停止任务

用户点击 `停止任务` 时：

1. 调用任务停止接口
2. 刷新任务状态区
3. 左侧任务卡状态同步更新


## 6. 前后端字段映射

## 6.1 任务字段

前端字段与后端 `/tasks` 对应关系：

- `任务名称` -> `name`
- `视频源` -> `source_url`
- `来源类型` -> `source_type`
- `关联通道` -> `channel_id`
- `帧间隔` -> `frame_interval`
- `状态` -> `status`
- `创建时间` -> `created_at`

## 6.2 算法字段

- `算法ID` -> `id`
- `算法类型` -> `algorithm_type`
- `模型` -> `model_id`
- `类别` -> `labels`
- `置信度` -> `confidence`
- `告警间隔` -> `alert_interval`
- `抓拍图` -> `need_snapshot`
- `告警视频` -> `need_video_clip`
- `前录像秒数` -> `video_before_seconds`
- `后录像秒数` -> `video_after_seconds`
- `是否画框` -> `need_overlay`
- `区域列表` -> `regions`

## 6.3 运行状态字段

- `运行状态` -> `runtime.status`
- `是否运行` -> `runtime.is_running`
- `最近分析时间` -> `runtime.last_analysis_at`
- `最近事件时间` -> `runtime.last_event_at`
- `错误信息` -> `runtime.last_error`
- `分析帧数` -> `runtime.frame_count`
- `事件数` -> `runtime.event_count`
- `算法运行详情` -> `runtime.models`


## 7. 前端实现拆分方案

为避免继续把所有逻辑堆进 `Channels.vue`，本轮建议新增以下单元：

- `frontend/src/api/tasks.ts`
  - 任务相关 API 调用
- `frontend/src/components/channels/TaskListPanel.vue`
  - 左侧任务列表
- `frontend/src/components/channels/TaskDetailPanel.vue`
  - 右侧任务详情
- `frontend/src/components/channels/TaskEditorModal.vue`
  - 新建任务弹窗
- `frontend/src/components/channels/AlgorithmEditorModal.vue`
  - 新增/编辑算法弹窗

`frontend/src/pages/Channels.vue` 仅负责：

- 子菜单切换
- 当前通道上下文
- 任务组件装配

不再直接承载所有任务表单逻辑。


## 8. 本轮实现范围

### 8.1 本轮要实现

- 在通道页新增 `任务管理` 子菜单
- 隐藏旧 `AI能力` 子菜单
- 基于当前通道展示任务列表
- 新建任务
- 查看任务详情
- 新增/编辑/删除算法
- 启动任务
- 停止任务
- 展示任务级运行状态

### 8.2 本轮不实现

- 任务区域的可视化编辑联动
- 任务带框流预览
- 旧 AI 配置自动迁移
- 事件页按任务/算法重构界面
- 录像页按任务/算法重构界面
- 多算法颜色图例展示


## 9. 后续演进路线

在本轮任务管理第一页稳定后，可按以下顺序继续扩展：

1. 区域配置与任务算法联动
2. 带框预览流按任务输出
3. 事件中心支持按任务/算法筛选
4. 录像中心支持按任务/算法筛选
5. 旧通道 AI 配置完全退场
6. 一个任务下多算法颜色区分和画框合流


## 10. 成功标准

本轮完成后，用户应能在单个通道中完成以下完整路径：

1. 进入 `任务管理`
2. 新建一个任务
3. 默认继承当前通道视频源
4. 给任务新增一个或多个算法
5. 配置类别、置信度、抓拍、录像等参数
6. 点击 `保存并应用`
7. 在同一页面看到任务运行状态

如果以上路径顺畅成立，则说明任务中心已经从后端能力真正进入用户可操作阶段。
